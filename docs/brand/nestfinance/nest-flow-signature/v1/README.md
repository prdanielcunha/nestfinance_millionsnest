# NestFinance - Nest Flow Signature - Kit Completo v1.0

## Conceito oficial
O N representa Nest/MillionsNest: um ninho aberto que acolhe, protege e organiza. O F representa Finance: uma estrutura vertical com três faixas que lembram registros, categorias, relatórios e evolução financeira.

## Arquivos mestres
- Fidelidade visual aprovada: `02_Logos_PNG/nestfinance-symbol-gradient-transparent-2048.png`
- Vetor editável: `01_Logos_SVG/nestfinance-symbol-vector-gradient.svg`
- Lockup principal: `01_Logos_SVG/nestfinance-logo-horizontal-dark.svg`

## Observação técnica
A prancha aprovada nasceu como imagem. Por isso, o pacote inclui dois mestres: uma extração raster de alta fidelidade e uma reconstrução vetorial suavizada para escala, impressão e desenvolvimento.

## Regras
1. Não distorcer, inclinar ou separar as partes do símbolo.
2. Não adicionar cifrão, moeda, gráfico externo, contorno ou sombra.
3. Em 16-24 px, prefira a versão flat ou monocromática.
4. Use o fundo Deep Black como opção principal.
5. A fonte recomendada é Inter Display / Inter. Os arquivos de fonte não fazem parte do pacote.
